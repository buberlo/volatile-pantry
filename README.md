# Volatile Pantry

> Volatile Pantry: cli app with voice control only.

A one-month cli project called Volatile Pantry — with voice control only. Built fast, shipped faster.

## Features
- Core cli loop that works in under 10 seconds of use
- The twist: with voice control only
- Zero-setup onboarding — useful within one minute
- Share/export so friends can join or compete

## Stack
- Rust + clap
- SQLite
- TypeScript

## Getting started
```
cargo run -- --voice-only
```
